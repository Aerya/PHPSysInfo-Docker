# 🖥️ PHPSysInfo-Docker

Conteneur Docker pour [phpSysInfo](https://github.com/phpsysinfo/phpsysinfo).

> ⚠️ Note : l’OS et la distribution peuvent parfois être mal détectés ou affichés de manière incomplète (bug connu de phpSysInfo).

---

## 🚀 Installation

### 1. Cloner le dépôt
```bash
git clone https://github.com/<ton-user>/PHPSysInfo-Docker.git
cd PHPSysInfo-Docker
```

### 1. Build et lancer
```bash
docker compose up -d --build
```
